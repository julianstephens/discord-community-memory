# discord-community-memory

Community Memory is an open-source, self-hostable Discord application that
preserves, organizes, and retrieves useful knowledge from community
conversations. Discord is effective for conversation but poor at preserving
institutional memory. Important decisions, explanations, recommendations, and
resources disappear into message histories. Search retrieves matching messages,
but it does not distinguish durable knowledge from incidental conversation.

Community Memory addresses this by creating a persistent, searchable knowledge
layer over selected Discord channels.

The goal is not to replace Discord or build another chat application. It is to
make existing conversations useful after they have ended.

```
Discord Conversations
Selected channels and manually saved messages

↓

Ingestion & Processing
Normalize · Deduplicate · Apply changes

↓

Persistent Community Memory
Knowledge records · Sources · Search index

↓

Discord Search & Retrieval
Access checked · Ranked · Source linked
```
